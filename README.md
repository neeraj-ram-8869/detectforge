# DetectForge

**Threat description in, validated Sigma detection rule out.**

An open-weight LLM drafts a Sigma rule, DetectForge tests it against labeled attack and benign
Windows logs, and the model refines it until it catches the attack without false positives.
Ships as an Agent Skill that follows the [Agent Skills Open Standard](https://agentskills.io).

Built for the DigitalOcean x MLH Hacktoberfest 2026 challenge.
